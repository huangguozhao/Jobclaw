# JobClaw 求职智能体领域

JobClaw 服务于求职信息获取、整理、匹配和持续跟进，并允许用户通过网页或即时通信渠道与专门的智能体协作。

## 用户与交互

**求职用户**：
使用 JobClaw 管理求职信息、获得岗位推荐并与智能体对话的人。
_Avoid_: 客户、账号、访客

**渠道身份**：
求职用户在某个外部通信渠道中的身份；一个求职用户可以绑定多个渠道身份。
_Avoid_: 用户、渠道用户

**会话**：
一个求职用户在特定渠道和对话场景中连续交互的上下文。
_Avoid_: 聊天记录、线程

**用户画像**：
由用户确认或从交互中提炼出的稳定求职事实与偏好集合。
_Avoid_: 记忆、简历

## 岗位信息

**岗位来源**：
能够提供一批原始招聘内容的页面、文件、图片或人工输入。
_Avoid_: 链接、爬虫任务

**采集任务**：
对一个或多个岗位来源执行读取、解析和结果汇总的一次工作。
_Avoid_: 爬虫、定时任务

**岗位草稿**：
从原始内容提取但尚未通过人工或规则审核的候选岗位信息。
_Avoid_: 岗位、脏数据

**正式岗位**：
已通过审核、可被用户检索和推荐的岗位信息。
_Avoid_: OC、招聘信息

**岗位推荐**：
基于用户画像和岗位条件生成的候选岗位集合及匹配理由。
_Avoid_: 搜索结果、猜你喜欢

## 智能体运行时

**渠道**：
接收外部消息并把响应送回同一通信媒介的连接方式。
_Avoid_: 平台、机器人

**业务智能体**：
围绕一个明确业务目标持续处理会话的智能协作者。
_Avoid_: 模型、工具、机器人

**意图**：
用户本轮消息希望完成的业务目标分类。
_Avoid_: 命令、关键词

**模型供应商**：
提供一种或多种模型能力及调用凭据的外部服务主体。
_Avoid_: 模型、接口地址

**工具**：
由业务智能体按需调用、会产生可观察结果或副作用的确定性能力。
_Avoid_: 智能体、插件

**计划任务**：
由用户或智能体定义，在未来某个时间或周期触发的工作安排。
_Avoid_: 采集任务、后台任务

## 记忆

**工作记忆**：
为完成当前会话而保留的近期消息与临时状态。
_Avoid_: 完整历史、用户画像

**会话摘要**：
从较早会话内容压缩出的事实性描述，用于在有限上下文中保持连续性。
_Avoid_: 用户画像、日志

**情景记忆**：
带有时间和来源的历史事件，描述用户曾经做过或经历过什么。
_Avoid_: 用户画像、会话摘要
