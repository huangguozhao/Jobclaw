# 分期需求文档

需求按依赖关系排序。推荐从第 00 期连续推进；有经验的开发者可以通过基线验收后从第 04 期开始。

| 期次 | 主题 | 核心训练 | 建议周期 |
|---|---|---|---|
| 00 | 工程基线 | 环境、构建、配置、健康检查 | 1～2 天 |
| 01 | 岗位目录 MVP | 数据建模、查询、前后端闭环 | 3～5 天 |
| 02 | 草稿审核与发布 | 状态机、后台 CRUD、事务 | 4～6 天 |
| 03 | 用户、认证与权限 | 身份、授权、数据隔离 | 4～6 天 |
| 04 | 多模块工程重构 | 模块接口、依赖方向、装配 | 3～5 天 |
| 05 | 统一消息与事件总线 | 适配器、事件驱动、幂等 | 4～6 天 |
| 06 | WebSocket 对话闭环 | 实时通信、会话、流式状态 | 4～6 天 |
| 07 | 多模型供应商 | 配置、模型选择、外部依赖隔离 | 4～6 天 |
| 08 | LLM 调用与工具执行 | ReAct、流式响应、工具安全 | 5～7 天 |
| 09 | 多 Agent 路由 | 注册、意图、命令、会话绑定 | 5～7 天 |
| 10 | 会话记忆 | 上下文窗口、持久化、摘要 | 5～7 天 |
| 11 | 用户画像与模型偏好 | 渐进采集、隐私、配置覆盖 | 5～7 天 |
| 12 | 多来源岗位采集 | 文件解析、网页抓取、异步任务 | 6～8 天 |
| 13 | AI 清洗与发布流水线 | 批处理、证据、审核、恢复 | 6～8 天 |
| 14 | 检索与个性化推荐 | 条件检索、解释性、反馈 | 5～7 天 |
| 15 | 计划任务与主动推送 | 调度、幂等、时区、补偿 | 5～7 天 |
| 16 | 外部 IM 渠道 | 多适配器、账号绑定、媒体 | 6～10 天 |
| 17 | 动态配置与可观测性 | 热更新、监控、审计 | 5～7 天 |
| 18 | 安全、可靠性与毕业项目 | 威胁建模、压测、综合交付 | 7～10 天 |
